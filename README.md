## 📌 Project Overview

This is **Project 1** of the Frontend Development Industrial Training Kit. A static webpage built with pure HTML and CSS, demonstrating mastery of semantic markup, visual architecture, and technical integrity.

**The Mission:** Construct a pixel-perfect static foundation before moving to dynamic logic.

---

## 🎯 Objectives

- Build a clean, readable layout using semantic HTML
- Apply CSS styling with DRY principles and BEM methodology
- Use CSS Grid for macro page structure
- Use Flexbox for micro component alignment
- Ensure all images have explicit width/height to prevent CLS
- Pass accessibility (A11Y) standards
